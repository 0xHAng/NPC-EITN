Use the following statement when describing access to this software:

```latex
\noindent The code supporting registered-image EITN calculation, association analyses and the four-model prediction workflow is available at \url{https://github.com/0xHAng/NPC-EITN} (version 0.2.3; \url{https://github.com/0xHAng/NPC-EITN/releases/tag/v0.2.3}). The repository includes software dependencies, input specifications, synthetic examples and aggregate reference results. Execution with clinical data requires approved registered images or curated inputs, available through the process described under Data availability. Participant-level data and fitted clinical models are not included. Reuse terms are described in the repository's LICENSE\_STATUS.md.
```

Coverage starts from registered images and curated tables. Raw DICOM
registration, all upstream radiomics and original patient figure artwork are
outside this package. No open-source license or clinical model release is
implied. Keep the existing confirmed Data availability request process separate.
